Sends our own make.fun username, one word and nothing else, for the judge to compare two at a time. The program writes the single username to `/output/entry.txt` — no explanation, no links, no pitch.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes `output/entry.txt` containing exactly `hupo3661`.
